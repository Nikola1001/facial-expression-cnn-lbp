# Архитектура

## Итоговая система

```text
                 ┌─ ResNet18 (512) ───────────┐
Лицо 48×48 ──────┤                            ├─ concat (640) ─ dense 256 ─ 7 логитов
                 └─ LBP 4×4×10 ─ dense (128) ─┘

                 Две такие CNN+LBP модели → усреднение вероятностей
                 каждого изображения и его отражения → P_CNN

То же LBP 160 → LayerNorm → dense 256 → dense 7 → P_LBP

                  0,8 × P_CNN + 0,2 × P_LBP → ответ
```

Для ResNet18 серое изображение растягивается до 112×112, повторяется в три канала и нормируется параметрами ImageNet. Отдельная ветвь получает 160 значений LBP того же изображения. После конкатенации обе ветви обучаются совместно. Вторая ResNet18 обучена с более сильной аугментацией и сглаживанием меток. Независимый LBP-классификатор обучен только на гистограммах FER2013 Training. Для отражённого изображения отражается и пространственная сетка гистограмм. Коэффициент 0,2 выбран на PublicTest.

Каждая ResNet18+LBP содержит 11 363 335 параметров, LBP-классификатор — 43 335. В `models/` находятся два checkpoint итогового ансамбля, LBP-классификатор и контрольная ResNet18 без LBP. `models/manifest.json` задаёт фактический состав модели для интерфейса и оценки.

## Исходная компактная CNN+LBP

Вход: выровненный или обнаруженный фрагмент лица 48×48, 1 канал. Значения пикселей приводятся к диапазону −1…1.

```text
Grayscale 48×48 ─ Conv 32 ─ Conv 64 ─ Pool ─ Conv 128 ─ Conv 128 ─ Pool
                 │                                        └ Adaptive avg pool 3×3 → 1152
                 └ Uniform LBP P=8,R=1 → 4×4×10 bins = 160
                                        ↓
                          concat 1312 → Dense 256 → Dropout → Dense 7
```

Каждая свёртка 3×3 сопровождается BatchNorm и ReLU. LBP код строится сравнением восьми соседей с центральным пикселем. Uniform шаблоны объединены по числу единиц (0–8), остальные попадают в десятый bin; в каждом из 16 регионов гистограмма нормируется по числу пикселей. Это даёт малый дескриптор локальной текстуры без отдельного обучения.
Всего обучаемых параметров: 578 535.

## Точные размеры и порядок вычисления

| Этап | Выход для одного изображения |
|---|---:|
| Фрагмент лица в оттенках серого | 1×48×48 |
| Conv 3×3, 32 канала + BatchNorm + ReLU | 32×48×48 |
| Conv 3×3, 64 канала + BatchNorm + ReLU; MaxPool 2×2 | 64×24×24 |
| Conv 3×3, 128 каналов + BatchNorm + ReLU | 128×24×24 |
| Conv 3×3, 128 каналов + BatchNorm + ReLU; MaxPool 2×2 | 128×12×12 |
| AdaptiveAvgPool 3×3; Flatten | 1152 чисел |
| LBP-гистограмма того же изображения: 4×4 регионов × 10 значений | 160 чисел |
| Конкатенация CNN и LBP | 1312 чисел |
| Linear + ReLU + Dropout 0,35 | 256 чисел |
| Linear | 7 логитов |

LBP вычисляется до нормализации пикселей для CNN: у каждого пикселя восемь соседей сравниваются с центром, полученный 8-битный код относится к одному из 10 типов. Изображение делится на 16 областей 12×12; по каждой считается нормированная гистограмма. При обучении аугментация сначала применяется к изображению, а затем **то же изменённое изображение** идёт в CNN и в вычисление LBP. Поэтому признаки двух ветвей соответствуют друг другу.

LBP — фиксированное преобразование без обучаемых весов. Градиенты проходят через CNN и полносвязный классификатор; веса первого полносвязного слоя учатся учитывать также LBP-признаки. Во время обучения семь логитов подаются в cross-entropy, а при предсказании softmax переводит их в вероятности.

Свёртки исходной компактной CNN обучены с нуля. В итоговом варианте они заменены предобученной ResNet18, при этом отдельная LBP-ветвь сохранена. Польза независимого LBP-классификатора дополнительно проверена сравнением с той же CNN без LBP на одинаковом разбиении.

Объединение выполнено перед классификатором: такое определение однозначно по размерности и позволяет напрямую сравнить вклад CNN и LBP. Четыре свёртки и две полносвязные операции сохранены; ORB не используется, чтобы избежать нестабильных дескрипторов на изображениях 48×48 и оставить проект компактным.

Интерфейс принимает одно изображение с лицом анфас. Для больших изображений OpenCV находит самый крупный фронтальный face crop; если лицо не найдено, интерфейс сообщает об этом. Предсказание относится к видимому выражению, а не к психологическому состоянию человека.
