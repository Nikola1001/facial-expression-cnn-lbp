# Результаты эксперимента

## Итоговая CNN+LBP модель

Две ResNet18 с отдельными LBP-ветвями обучены на исходном FER2013 CSV. Их вероятности после горизонтального отражения усредняются, затем добавляется 20% вероятностей независимого LBP-классификатора. Эпохи и коэффициент смешивания выбирались на PublicTest. Параметры выбранной модели сохранены в `models/manifest.json` и проверены повторной загрузкой из файлов репозитория.

| Модель / набор | Accuracy | Macro F1 | Объём |
|---|---:|---:|---:|
| Итоговая, FER2013 PublicTest | 70,91% | 69,90% | 3 589 |
| Итоговая, FER2013 PrivateTest | **71,58%** | **70,57%** | 3 589 |
| Итоговая, CK+ CSV, внешняя оценка | 78,16% | 50,34% | 902 |

Проверка вклада LBP на **одной и той же CNN** (ResNet18 без LBP, одна и та же эпоха, одинаковое отражение и те же изображения):

| FER2013 PrivateTest | Accuracy | Macro F1 |
|---|---:|---:|
| CNN без LBP | 70,13% | 68,93% |
| Та же CNN + отдельный LBP-классификатор, вес 0,2 | **70,24%** | **69,24%** |

Измеренный прирост составляет **0,11 процентного пункта accuracy** (4 дополнительных верных ответа из 3 589) и **0,31 пункта macro F1**. На PublicTest та же пара дала 70,08% → 70,19% accuracy. LBP-классификатор отдельно достиг 39,43% на PublicTest. Его вклад существует, но невелик: этот опыт не доказывает устойчивый прирост на других запусках или выборках. В другом контроле простое раннее объединение LBP с ResNet18 оказалось хуже модели без LBP; поэтому независимая ветвь с поздним смешиванием оставлена в итоговой системе.

PrivateTest просматривался в ходе нескольких последовательных экспериментов. Поэтому приведённые тестовые числа следует считать **исследовательской оценкой**, а не результатом заранее зарегистрированного единственного финального запуска. В CK+ CSV нет ID участников, его 593 нейтральных примера делают общую accuracy малоинформативной; на шести ненейтральных классах итоговая модель дала 58,25%.

## Исходная модель

 Модель обучалась 30 эпох на 28 709 изображениях FER2013. Лучшая эпоха 23 выбрана по macro F1 на PublicTest (3 589 изображений). Финальные значения ниже получены на отдельном PrivateTest (3 589 изображений), который не использовался для выбора эпохи.

| Набор | Accuracy | Macro F1 | Balanced accuracy | Объём |
|---|---:|---:|---:|---:|
| FER2013 PrivateTest | 64,17% | 61,88% | 63,91% | 3 589 |
| CK+ CSV, внешняя проверка | 86,14% | 64,99% | 64,02% | 902 |

В CK+ CSV из исходных 920 строк исключены 18 примеров класса contempt, отсутствующего в FER2013. Внешняя оценка сделана тем же checkpoint без обучения на CK+ и без выбора параметров по CK+. Нейтральные примеры составляют 593 из 902 (65,7%), поэтому общая accuracy 86,14% не отражает одинаковое качество на всех эмоциях. Для шести ненейтральных классов суммарная accuracy равна 67,64%.

| Класс | FER2013 recall | CK+ recall |
|---|---:|---:|
| angry | 54,4% | 35,6% |
| disgust | 74,5% | 50,8% |
| fear | 33,5% | 28,0% |
| happy | 84,5% | 100,0% |
| sad | 54,5% | 50,0% |
| surprise | 77,2% | 88,0% |
| neutral | 68,7% | 95,8% |

Главная слабость — распознавание fear; в FER2013 его часто путают с sad, в CK+ angry часто путается с neutral и disgust. Графики показывают рост train macro F1 при замедлении роста validation после 23-й эпохи, поэтому выбран более ранний checkpoint.
